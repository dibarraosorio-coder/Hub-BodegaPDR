# 🔄 Hub Centralizado de Abastecimiento y Compras

<img width="1888" height="868" alt="image" src="https://github.com/user-attachments/assets/07b071ca-20d2-4e05-b480-dfb6eb64e88c" />


**Plataforma integral in-house para la gestión end-to-end del ciclo de abastecimiento: desde el análisis de rotación y alertas de quiebre, hasta el seguimiento de órdenes de compra y optimización del flujo de caja.**

### 🎯 El Desafío Operativo
La gestión de compras dependía de cruzar múltiples reportes estáticos y planillas desconectadas. Esta fragmentación impedía tener una visión global del abastecimiento, aumentando el riesgo de quiebres de stock en operaciones críticas, generando sobre-stock por compras mal calculadas y dificultando el seguimiento de los pedidos en tránsito.

### 🚀 Ecosistema y Módulos del Hub
Desarrollé este Hub para unificar toda la información del departamento de adquisiciones en una sola interfaz dinámica:

* **Planificador Proactivo (Puntos de Reorden):** Módulo que calcula y alerta automáticamente sobre las necesidades de reposición basándose en niveles de stock crítico y datos reales de consumo operativo.
* **Tracking de Órdenes de Compra (OC):** Seguimiento centralizado de los pedidos pendientes con proveedores. Permite visualizar qué viene en camino, fechas estimadas de llegada y evitar urgencias logísticas.
* **Control de Rotación de Inventario:** Análisis continuo del flujo de mercaderías para identificar productos de alta rotación (fast-movers) y obsolescencia, ajustando las políticas de compra.
* **Optimización de Presupuesto:** Visibilidad directa del impacto financiero de las compras planificadas, permitiendo una gestión más eficiente del flujo de caja del área logística.

### 🛠️ Stack Tecnológico
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (Diseño orientado a Dashboards operativos).
* **Backend y Pipeline de Datos:** Google Apps Script y Google Sheets como motor de base de datos relacional.
* **Integración de Datos:** Consolidación automatizada de información de inventario y estado de compras proveniente del ERP.
